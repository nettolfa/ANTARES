# Antares

Protótipo de sistema de gestão para pequenos negócios: tela de login e painel com páginas de dashboard, clientes, estoque e financeiro.

**Ver online:** https://antares-gamma.vercel.app/

## O que tem
- Tela de login
- Painel com navegação entre dashboard, clientes, estoque e financeiro
- Cadastro de clientes com JavaScript (`js/cliente.js`)

## Tecnologias
HTML, CSS, Bootstrap e JavaScript. Publicado na Vercel.

Projeto de estudo.
